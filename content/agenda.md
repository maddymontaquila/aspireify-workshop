# Aspireify Your Stack: Proposed 2-Day Workshop Agenda

## Workshop promise

By the end of Day 1, attendees should have an existing app running locally through Aspire. By the end of Day 2, they should have a practical path toward deployment, observability, and deeper Aspire customizations for their real app.

---

## Day 1: Aspirifying for local development

| Time | Session | Focus |
|---|---|---|
| 08:00–09:00 | Breakfast | Arrival, setup, informal app/context triage |
| 09:00–10:15 | Welcome + Aspire mental model | What Aspire is, what “Aspirifying” means, AppHost/resource model, dashboard, orchestration vs deployment |
| 10:15–10:30 | Morning break |  |
| 10:30–12:00 | First Aspirification pass | Add Aspire to an existing app, wire projects/services, executables, containers, environment variables |
| 12:00–13:00 | Lunch |  |
| 13:00–14:15 | DevEx: commands, parameters, and config | Parameters, secrets, launch profiles, repeatable local workflows, command customization |
| 14:15–15:15 | Resources and dependencies | Databases, Redis, queues, external services, connection strings, health checks |
| 15:15–15:30 | Afternoon break |  |
| 15:30–16:30 | Observability and dashboard deep dive | Logs, traces, metrics, debugging multi-service apps |
| 16:30–17:00 | Open lab / app triage | Attendees work on their own apps with support from Maddy and the Aspire team |

---

## Day 2: From local dev to deployment and customization

| Time | Session | Focus |
|---|---|---|
| 08:00–09:00 | Breakfast | Optional help with setup issues or Day 1 carryover |
| 09:00–10:15 | Recap + real-world troubleshooting | Address common issues from Day 1, use attendee apps as teaching examples |
| 10:15–10:30 | Morning break |  |
| 10:30–12:00 | Deployment path 1: Docker Compose and containers | Containerization, generated artifacts, networking, env mapping, local-to-prod gaps |
| 12:00–13:00 | Lunch |  |
| 13:00–14:00 | Deployment path 2: cloud deployment concepts | Azure Container Apps/Azure resources if relevant, infra shape, publish/deploy mindset |
| 14:00–15:15 | AI-ifying with Aspire | Adding AI services, model endpoints, local/cloud model config, prompts/secrets, observability for AI calls |
| 15:15–15:30 | Afternoon break |  |
| 15:30–15:40 | Workshop evaluation | Required organizer slot |
| 15:40–16:20 | Advanced customization lightning menu | Attendee-voted topics: custom resources, lifecycle hooks, integration testing, CI/CD, service discovery, health checks |
| 16:20–16:50 | Show, tell, and next steps | Volunteers demo progress, discuss remaining gaps and migration plans |
| 16:50–17:00 | Soft close / office hours | Official wrap, optional final help |

---

## Suggested teaching rhythm for each technical block

**Concept → live demo → attendee exercise → common failure modes → open lab**
